# Demo script and submission checklist (V4)

Check the official ARM Bharat Challenge page for the exact deadline and artefacts; confirm before you record.

## 4-5 minute demo (physical phone, airplane mode ON)
1. Show airplane mode and the Model screen: status Ready, model file name, size.
2. Run the self-test; show tokens/second on screen.
3. Plan screen: type a real goal ("I want to become a VLSI design verification engineer in 3 months, 8 hours a week, interested in UVM"). Show "Llama is reading your goal", then the structured goal ("understood by Llama") and the week-by-week plan.
4. Take a quiz on a planned subject; return to the plan and show the revision items and notes that appeared.
5. Open a planned lesson; ask the tutor a question; show the answer with "Llama on-device, grounded in <lesson>".
6. Ask "What should I study this week?" and tap "Ask Llama for a coaching note".
7. Optional: HDL Studio running a Verilog demo.
Say clearly what is on-device (everything) and what is rule-based (schedule, BKT, retrieval).

## Submission checklist
- [ ] Source code: this repository (push to GitHub, include docs/ and tools/).
- [ ] Application: release APK (`gradlew.bat assembleRelease`) or debug APK; state that the model is installed separately and give the guide link, or confirm whether the organisers want the model bundled.
- [ ] Demonstration video recorded on the phone.
- [ ] Technical report: docs/TECHNICAL_REPORT.md with section 5 filled from your own run, exported to PDF.
- [ ] Self-test report saved from the app (Diagnostics > saved reports).
- [ ] README updated with your name, team and links.
